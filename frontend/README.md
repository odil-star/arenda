# Arenda — фронтенд

Интерфейс SaaS-сервиса для владельцев недвижимости: объекты, арендаторы, договоры, платежи.
Основной сценарий — телефон: на мобильном нижняя навигация, на десктопе сворачиваемая боковая панель.

**Стек:** React 18 · Vite · TypeScript (strict) · Tailwind CSS v4 · Radix UI (компоненты в стиле shadcn/ui) · lucide-react ·
React Router v6 · TanStack Query v5 · React Hook Form + Zod · axios · i18next (ru / uz) · date-fns · Recharts.

## Запуск

Нужен Node.js 20+.

```bash
cd frontend
cp .env.example .env      # при необходимости поменяйте адрес API
npm install
npm run dev               # http://localhost:5173
```

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер Vite |
| `npm run build` | проверка типов (`tsc -b`) и production-сборка в `dist/` |
| `npm run lint` | ESLint |
| `npm run preview` | локальный просмотр сборки |

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `VITE_API_URL` | `http://localhost:8000` | Адрес Django API без `/api` и завершающего слеша |

## Настройка CORS на бэкенде

Фронт обращается к API напрямую (без прокси), поэтому его origin должен быть разрешён в `django-cors-headers`.
В бэкенде список берётся из переменной `CORS_ORIGINS` (через запятую):

```bash
# backend/.env
CORS_ORIGINS=http://localhost:5173
```

- В `config.settings.dev` значение по умолчанию уже `http://localhost:5173`.
- В `config.settings.prod` по умолчанию список пуст — укажите реальный домен фронта, например
  `CORS_ORIGINS=https://app.example.uz`.
- Авторизация идёт заголовком `Authorization: Bearer …`, cookies не используются, поэтому
  `CORS_ALLOW_CREDENTIALS` не нужен.

Если фронт и API отдаются с одного домена (например, через nginx: `/` → фронт, `/api/` → Django),
CORS не нужен — задайте `VITE_API_URL` равным этому домену.

## Структура

```
src/
  api/          клиент axios с refresh-токеном, типы ответов, хуки TanStack Query
  components/
    ui/         базовые компоненты (Button, Input, Dialog, Select, Tabs…)
    layout/     каркас: боковая панель, нижняя навигация, шапка, переключатели
    common/     общие блоки: список-таблица, состояния (пусто / ошибка / загрузка), поля формы
  features/     экраны: auth, dashboard, properties, tenants, leases, payments
  lib/          форматирование (суммы, даты), валидация, тема, хуки
  locales/      ru.json, uz.json (+ типизация ключей)
  routes/       маршруты и guard'ы
```

## Как устроено

- **Авторизация.** Токены в `localStorage`. Interceptor подставляет access-токен; при 401 один раз
  обновляет его через `/auth/token/refresh/` (одновременные запросы ждут один общий refresh) и повторяет запрос.
  Если refresh не удался — выход и переход на `/login`. Приватные маршруты закрыты `RequireAuth`.
- **Данные.** Все запросы — через TanStack Query; после изменений сбрасывается кеш связанных разделов
  (например, оплата обновляет платежи, договоры и дашборд). Фильтры и вкладки хранятся в URL.
- **Ошибки API** `{поле: [сообщения]}` показываются под соответствующими полями; общие (`detail`,
  `non_field_errors`) — над формой.
- **i18n.** Ключи типизированы: опечатка в ключе — ошибка компиляции. `uz.json` проверяется на ту же
  структуру, что и `ru.json`.
- **Форматы.** Суммы — «2 000 000 сум» / «2 000 000 soʻm», даты — ДД.ММ.ГГГГ, цифры с `tabular-nums`.
- **Доступность.** Подписи у всех полей, видимые фокус-кольца, цели нажатия от 44 px на телефоне,
  статусы всегда с иконкой и текстом, ссылка «Перейти к содержимому», учёт `prefers-reduced-motion`.

## Особенности API, которые учитывает фронт

- Вход — по **email** (`USERNAME_FIELD = "email"`), регистрация принимает `email, password, first_name, last_name, phone`.
- `GET /api/properties/` не отдаёт занятость объекта. Статус «Сдан / Свободен» фронт вычисляет по действующим
  договорам (`/api/leases/?status=active&page_size=100`); фильтр «Сдан / Свободен» работает на клиенте по
  страницам из 100 объектов. Если на бэкенде появится поле `is_occupied` с фильтром, это место стоит упростить
  (`useOccupiedPropertyIds` в `src/api/hooks.ts`).
- Частично оплаченные платежи бэкенд отдаёт отдельным статусом `partial`, поэтому на экране платежей
  есть вкладка «Частично».
- Привязка арендатора к Telegram — одноразовый код (`POST /api/tenants/{id}/link-code/`), его можно получить в форме арендатора.
